# 更新日志

## 0.0.1 - 2026-11-02

- 基于上游易翻翻译 v2.22.2 建立本仓库初版，保留原有翻译、图片翻译、朗读及命名功能。
- 新增 LibreTranslate 在线及本地实例支持，提供服务地址、可选 API Key 和配置备份。
- 使用 Libre 自身的自动语言检测，修复手选翻译方向的显示与请求同步。
- 从实例 `/languages` 获取语种并按 `targets` 过滤方向，默认自动检测到中文简体。
- 语种列表优先排列中文简体、英文，其余保持接口顺序；刷新时保留手选方向。
- 接入官方厂商图标，移除自动复制悬浮说明，将设置文案统一为 ZTools。
- 作者归属统一为 Augenstern，主页设为 https://github.com/Augenstern-O，版本从 v0.0.1 起。
- 添加本地回归检查及 ZPX 打包、校验脚本。

上游来源及原作者见本目录 AGENTS.md 和 README.md；上游版本号仅用于溯源。
